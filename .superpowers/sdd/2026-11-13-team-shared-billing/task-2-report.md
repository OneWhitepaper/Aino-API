# Task 2: billing integration

Implemented per-request funding snapshots on copied API keys; actor identity, user/key quotas, RPM, group/model permission checks and desktop `balance|subscription` response values remain intact. Configured source ordering considers a conservative full-request quote. Shared subscriptions grant only their explicitly selected active group, including normal key create/update binding. Existing unconfigured nonowners retain the old path; team owners activate implicit personal funding (domain worker) while preserving the legacy group-specific source: subscription groups stay on their own subscription; standard groups stay on their balance.

Shared and configured bounded-text personal calls reserve the real payer balance/subscription windows in PostgreSQL. Settlement/refund joins the existing usage-dedup transaction. Personal/source overages debit only the authorized hold, persist the unpaid amount and prevent further personal reservations. Root owns legacy owner pool-floor protection and migration 259; its narrow protected balance call is preserved in this commit.

Dispatch uses the stable desktop operation/call ID or `Idempotency-Key`, scoped to key+actor; otherwise at-most-once covers that single HTTP dispatch. Admission ownership rejects another in-flight handler before it can reuse/release a hold. A permanent global operation claim and source `reserved -> dispatched` CAS commit together before the actual network call. Redirects/body replay and second paid dispatches fail closed. Unknown outcomes keep their holds; there is no automatic timeout refund. Local undispatched cleanup is conditional on DB state and admission ownership. A complete structured pre-generation provider rejection without usage can release a dispatched hold. Transport/5xx/usage-bearing errors retain it.

The quote supports self-contained `/messages`, `/responses`, `/chat/completions` text, ordinary function tools and streaming. It injects 4096 output tokens only when absent, preserves explicit output limits, uses complete request bytes plus framing allowance, maximum cache/context/service-tier/reasoning/official DeepSeek/time/peak pricing and caller-specific group rates. The final transformed outbound request must retain an output cap. OAuth transforms removing caps therefore reject before paid dispatch. Shared remote media, hosted tools, conversation references, WebSocket, composite models and other unbounded adapters reject with `TEAM_FUNDING_COST_UNBOUNDED`. Existing personal-only image/audio and other unsupported adapters keep their established personal billing path with no shared fallback. Dispatched unknown holds currently require manual operational reconciliation; no new reconciliation API is included.
