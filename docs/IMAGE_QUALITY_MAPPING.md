# 图片画质适配

桌面端的默认出图质量为 `auto`（自动）。部分 OpenAI 兼容上游使用 `1k`、`2k`、`4k` 等不同的画质参数，需要由管理员明确配置适配规则。

在 **账号管理 → 编辑 OpenAI API Key 账号 → 图片画质适配** 中新增规则，填写最终上游模型的精确名称、客户端画质和上游画质。例如，已确认支持 `1k` 的 Nano Banana 2 上游可以配置：

```json
{
  "image_quality_mapping": {
    "Nano Banana 2": { "auto": "1k" }
  }
}
```

该对象保存在账号的 `credentials` 内。规则仅作用于被调度选中的 OpenAI API Key 账号，并在渠道、账号的模型名称映射完成后查找最终模型名称。省略画质参数的请求按 `auto` 查找；未匹配到规则的参数保持原样。OAuth 和其他平台不应用这套规则。

支持客户端画质 `auto/low/medium/high/xhigh/max`，上游画质另支持 `1k/2k/4k`。管理员应根据上游实际支持的参数配置；系统不会推断这些档位之间的对应关系。不支持通配符。

规则同时适用于生成图片、JSON 改图和 multipart 文件改图。转发只改写模型名称和已配置的画质字段，保留其他请求字段与上传文件。客户端模型身份、原始请求画质及现有权限、计费流程不变。

删除所有规则并保存会写入空对象 `{}`，恢复原样转发。配置错误会在管理员保存时拒绝；异常历史配置在转发前拒绝，不会把请求发送到上游。日志事件 `openai_images.quality_mapped` 仅记录账号 ID、模型及适配前后画质，不记录图片或提示词。

本功能无需数据库迁移，不改变桌面端的默认画质。
