# 智商检测

用户入口为 `/iq-test`，位于用户导航“智力雷达”下面。页面提供糖果推理与鹈鹕骑行两项独立任务，参考 [manxue.ai](https://manxue.ai/api) 的交互方式。实际请求由本站后台直接发送到用户选择的 API 服务商，不使用该网站作为代理。

## 使用

1. 选择题目，可通过“查看题目”查看后台实际使用的提示词。
2. 选择本站 API Key，或填写自定义接口地址与 Key。自定义接口须支持 Responses API，通常填写 `https://api.example.com/v1`。
3. 本站 Key 自动获取模型；自定义接口在填写连接信息后获取，也可点击“获取模型”刷新或手动填写模型 ID。
4. 选择接口支持的推理强度；未知能力时使用默认值，也可在更多设置中显式指定。可选择 Priority 与流式/完整返回，是否支持取决于接口。
5. 点击开始检测。检测按正常 API 用量计费；取消不能退回已产生的用量。
6. 查看模型回答、判定依据、用量明细及个人历史。刷新页面会重新连接已有任务。

每次检测最长 10 分钟，最多 8,192 输出 Token（包含推理 Token）。最多 8 个检测同时运行，每个用户最多 1 个；模型发现最多 4 个并发请求，每次最长 20 秒。响应总大小最多 2 MiB，可见输出最多 256 KiB。

## 结果含义

- 糖果推理只检查最后一行的整数答案，可带“最终答案：”或“Final answer:”前缀。答案为 21 判为通过，其他整数判为未通过；无法识别则未判定。推理中出现 21 不算通过。
- 鹈鹕骑行完成后保留原始代码并提供静态 HTML/SVG 预览，由用户判断绘图质量。预览与下载的静态作品均禁用脚本、表单、外部资源和页面跳转；原始回答仍可复制、查看。
- 请求失败、未收到完成事件、超时、取消或服务中断均不作能力判定。失败时保留已收到的可见文本。
- 单项任务不能判断模型真实身份、智商或整体能力。

速度为输出 Token / 总耗时，包含等待和推理时间。输出 Token 已包括推理 Token，不重复累加。缺失用量、缺失参考单价或不明确的服务等级保持未知，显示为 `—`；参考费用复用本站价格计算逻辑，但不代表用户实际账单。实际扣费请查看本站使用记录或外部服务商账单。

## 接口

以下接口均位于 `/api/v1` 下，要求用户 JWT，结果只能由本人读取或取消，响应为 `Cache-Control: private, no-store`。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/iq-tests/options` | 当前题目提示词 |
| GET | `/iq-tests/keys` | 本人可用 Key 的名称和脱敏尾号 |
| POST | `/iq-tests/models` | 从选中接口获取模型与已知推理强度 |
| POST | `/iq-tests` | 发起或复用同一请求编号的任务 |
| GET | `/iq-tests?offset=0` | 本人历史，每页 20 项 |
| GET | `/iq-tests/:id` | 完整结果或当前流式输出 |
| DELETE | `/iq-tests/:id` | 取消任务 |

发起请求使用随机 UUID `request_id`；相同编号与相同请求复用已存任务，相同编号但不同设置返回冲突。服务不会自动重试付费生成。数据库事务在多实例间限制并发，终态只能从 `running` 原子转换，取消后的迟到结果不能覆盖记录。任务超过截止时间后显示中断，不自动重新产生付费请求。

## 数据与连接

迁移 `248_user_iq_tests.sql` 保存本人任务配置、结果、用量、时间与请求指纹，不保存 API Key。外部凭证仅在当前运行内存中使用，面板审计省略带凭证的完整请求体，上游错误只暴露固定错误码。模型输出中的本次凭证会被替换为 `[redacted]`。

本站 Key 通过固定路径的内部 HTTP 适配器进入现有 `/v1/models` 和 `/v1/responses` 网关，保留解析后的真实客户端 IP，并重新执行正常 API Key 权限、IP ACL、额度、模型准入及计费流程。适配器不监听网络端口，也不接收用户指定的任意内部路径。

自定义接口仅允许公网 HTTPS 的默认 443 端口，禁止地址中的用户名、密码、查询、片段和 Key。DNS 在实际连接时解析、校验并固定到公有 IP，拒绝混合内网解析，不使用代理，也不跟随重定向。
